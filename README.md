# bitwarden_audit
Локальный Python-скрипт, который читает экспорт Bitwarden и показывает:     
1. сколько паролей повторяются;
2. в каких записях они повторяются: имя, логин, URI, папка;
3. при желании можно показать сам пароль;
4. можно искать записи по паролю;

Как запускать
1. Просто найти повторяющиеся пароли

```bash 
python3 bw_audit.py bitwarden_export.json
```

Пример вывода:
```
=== Повторяющиеся пароли ===
Записей с паролями: 184
Уникальных паролей: 141
Паролей повторяется (порог >= 2): 19
Записей с повторяющимися паролями: 52

================================================================================
Пароль повторяется 4 раз | длина: 14 | sha256_12: 9f2c4d1ab77e
  - GitHub | логин: user@example.com | uri: https://github.com | папка: Work
  - Old Forum | логин: user | uri: https://forum.example.com
  - Test Server | логин: admin | uri: https://10.0.0.5
```
По умолчанию скрипт не показывает сам пароль, только:

  * количество повторов;
  * длину пароля;
  * короткий идентификатор sha256_12;
  * список записей.

2. Показать повторяющиеся пароли открыто
   ```bash
   python3 bw_audit.py bitwarden_export.json --show-password
   ```
   **Осторожно: пароль появится в терминале и может остаться в истории терминала, логах, scrollback-буфере.**

3. Найти все записи по точному паролю
Лучше использовать интерактивный ввод, чтобы пароль не попадал в историю команд:
    ```bash
    python3 bw_audit.py bitwarden_export.json --ask-password
    ```
    Скрипт спросит:
   ```
   Введите пароль для поиска:
   ```
   Если нужно показать найденный пароль:
   ```bash
   python3 bw_audit.py bitwarden_export.json --ask-password --show-password
   ```
4. Поиск по части пароля
   Например, найти все пароли, которые содержат 2020:
   ```bash
   python3 bw_audit.py bitwarden_export.json --contains --ask-password
   ```
   Затем вводите:
   ```
   2020
   ```
   Если хотите показать найденные пароли:
   ```bash
   python3 bw_audit.py bitwarden_export.json --contains --ask-password --show-password
   ```
5. Посмотреть пароль по идентификатору из отчёта
   В отчёте вы увидите строки вроде:
   ```bash
   Пароль повторяется 3 раз | длина: 12 | sha256_12: 51ab9d27c4ef
   ```
   Чтобы раскрыть именно этот пароль:
   ```bash
   python3 bw_audit.py bitwarden_export.json --reveal-sha12 51ab9d27c4ef
   ```
   Это удобнее, чем показывать сразу все пароли через --show-password.
6. Дополнительно проверить слабые пароли
   ```bash
   python3 bw_audit.py bitwarden_export.json --weak
   ```
   Скрипт отметит, например:

    длина меньше 12;
    только цифры;
    только буквы;
    очень мало уникальных символов;
    пароль совпадает с логином;
    пароль содержит логин;
    пароль из списка часто используемых.

   **Важные замечания по безопасности**

    Файл экспорта содержит все пароли в открытом виде.
    Не отправляйте его по почте, не загружайте в облако, не прикрепляйте к тикетам.
    Лучше делать анализ на зашифрованном диске.
    Например, в зашифрованном контейнере или на зашифрованном разделе.
    Не используйте --search-password с паролем в командной строке.
    История shell может сохранить пароль. Лучше:
    ```bash
    python3 bw_audit.py export.json --ask-password
    ```
    **Не показывайте пароли в терминале без необходимости.**

    **Особенно если:**

    * ведется логирование;
    * вы шарите экран;
    * запускаете скрипт в CI;
    * вывод может попасть в файл.

    **После анализа удалите экспорт.**
    **Для обычных файлов лучше хотя бы удалить и очистить корзину. Для чувствительных данных лучше использовать зашифрованный том, который можно удалить целиком.**
